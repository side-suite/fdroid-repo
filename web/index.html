SideSuite App Pack

This host serves an F-Droid repository for the SideSuite apps — SideType, SideCall and SideHome — for the Sidephone SP-01.

It is meant to be added to the SP-01's Library app, not browsed here. Scan the QR code at sidesuite.app/install with the Library's scanner, or add this address by hand:

https://fdroid.sidesuite.app/fdroid/repo

Verify the signing fingerprint matches before trusting the pack — it is published on the install page.

Browse the raw repository index

Not affiliated with Sidephone. Every app here is also published as a signed APK on GitHub Releases, for Obtainium or manual install.
